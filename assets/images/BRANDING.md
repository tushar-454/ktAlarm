# ktAlerm artwork

Created with the built-in image generation tool. The production assets are `icon.png` (opaque 1024px launcher icon), `splash-icon.png` (transparent 1024px splash logo), `android-icon-foreground.png` (transparent adaptive artwork with extra safe-area padding), `android-icon-monochrome.png` (the same alpha silhouette, tinted by Android), and `favicon.png` (64px).

The themed icon deliberately uses the foreground's alpha; Android ignores its RGB colors. The native splash uses the transparent artwork centered over `#0E1116` in both system appearances.

The PNG thumbnails in `backgrounds/` are generated by `scripts/generate-background-presets.cjs`, independently of the artwork generator.

## Launcher prompt

Use case: logo-brand. Asset type: production mobile launcher icon for ktAlerm, a wake-up alarm app with an orange accent and dark interface. Create a polished minimal warm orange alarm-clock emblem, a round clock face with two simple bell silhouettes and two clearly readable cream clock hands at 7 o'clock, gentle dimensional lighting, bold clean silhouette readable at 48px. Center the complete clock emblem within the central 60 percent of a square canvas with generous empty safe padding for Android adaptive masks. Scene/backdrop: solid uniform deep charcoal #0E1116, full bleed square, no rounded outer tile or border. Color palette: orange #FF8A3D, warm amber highlights, cream hands. No letters, no words, no watermark, no extra symbols. Output square 1024x1024.

## Splash / adaptive foreground prompt

Use case: background-extraction. Asset type: transparent foreground logo for ktAlerm's dark native mobile splash screen and Android adaptive launcher icon. Edit the provided orange alarm clock icon. Remove only the charcoal backdrop completely, including any dark exterior drop shadow or vignette. Preserve the complete orange clock, bells, feet, dark clock face and cream hands exactly. Keep the square canvas and center position, leave generous transparent padding so the clock occupies the central 60 percent of the square. Output 1024x1024 PNG with real transparent alpha. No added text, lettering, frame, or new objects.
